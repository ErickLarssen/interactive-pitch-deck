## Regras
- Nunca usar tamanho de texto de site convencional (ex.: 14px).

- Contraste suficiente sobre vídeo/imagem de fundo (overlay obrigatório).
- Navegação 100% funcional via teclado.
- Respeitar prefers-reduced-motion.
- Foco visível em todo elemento interativo (cards, botões, avatares).
