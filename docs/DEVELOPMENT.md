# DEVELOPMENT.md

## Instalação e scripts
A definir após o scaffold inicial do Vite (próxima fase, após sua
aprovação). Previsto: npm install / npm run dev / npm run build /
npm run preview.

## Convenções
- Componentes: PascalCase. Hooks: useCamelCase. Dados: camelCase.ts.
- Um componente por arquivo. Slides isolados em src/slides/.
- Commits pequenos e descritivos.

## Git
Branch por funcionalidade (ex.: feat/team-slide, feat/timer-system).
Equipe pequena — revisão leve, mas nunca commit direto quebrando main
na semana da apresentação.
